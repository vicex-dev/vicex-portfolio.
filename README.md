# vicex portfolio

A responsive beginner frontend developer portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — layout, colours, responsive styles and CSS illustration
- `script.js` — mobile navigation, reveal animations, year and contact form

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser. For a smoother development workflow, use VS Code with the Live Server extension.

## Personalise before publishing
1. In `script.js`, replace `your-email@example.com` in `YOUR_EMAIL` with the email address you want clients to use.
2. In `index.html`, replace the `#` social profile links with your real GitHub, LinkedIn and other profile URLs. Remove any social link you do not use.
3. The three project cards are concept/demo projects, not client work. Build the projects yourself, then add their real live demo and source-code links.
4. Update the skill progress bars in `index.html` as your skills improve. They are only self-assessed placeholders.
5. Review your name/brand, wording and contact details before publishing.

## Important
The contact form uses a `mailto:` link. It opens the visitor's email app; it does not send or store messages on a server. A backend or form service would be needed for a form that submits directly on the website.
